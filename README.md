## Sobre este portfólio

Um site estático, sem framework e sem etapa de build, feito para ser rápido e fácil de manter.

- Site bilíngue: botões com as bandeiras do Brasil e dos EUA trocam todo o conteúdo entre português e inglês, e a escolha fica salva no navegador.
- Rolagem suave com [Lenis](https://github.com/darkroomengineering/lenis) e barra de progresso.
- Visual com referências ao universo de programação: janela de código digitada no início, seções como comentários e processo de trabalho em formato de commits.
- Layout responsivo para desktop, tablet e celular.
- Acessibilidade: navegação por teclado, foco visível, contraste adequado, respeito a `prefers-reduced-motion` e ao tema claro/escuro do sistema.
- HTML semântico, metadados para SEO e compartilhamento social.
- Botões de contato que abrem o WhatsApp com a mensagem inicial preenchida.

## Executar localmente

Não há dependências para instalar. Clone o repositório e abra o `index.html` no navegador, ou, se preferir um servidor local:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.
